# Superstore Sales Dashboard

This project is an interactive Power BI dashboard created to analyze sales performance, profit trends, customer insights, and regional sales distribution using the Superstore dataset.

## Tools Used
- Power BI
- DAX
- Data Visualization

## Dashboard Features
- KPI Cards
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top 5 Customers Analysis
- Interactive Slicers & Filters

## Key Insights
- Identified top-performing categories and regions
- Analyzed overall sales and profit trends
- Built interactive visuals for business decision-making
